# Docs for AI agents

Two self-contained guides written so that an AI agent (or a new contributor) can get to work after one read. They describe version 1.2.0.

| Guide | Read it to… |
| --- | --- |
| [DEVELOPING.md](DEVELOPING.md) | Change or extend the program: repository map, data model, how edits and undo work, host API, recipes (new element, property type, node, block, AI tool, string, format change), conventions, build and test commands |
| [USING.md](USING.md) | Make a game with the editor: the story graph, scenes and visuals, the script format, dialogue and choices, sound, animation (keyframes, expressions, precompose), interactions, translations, preview and export, the built-in AI assistant's tools |

两份给 AI 阅读的指南：[DEVELOPING.md](DEVELOPING.md) 讲程序的结构和如何修改扩展；[USING.md](USING.md) 讲如何用软件制作画面、动画、场景、声音和流程图。
