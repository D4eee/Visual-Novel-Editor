# Keyboard shortcuts

**Mod** is ⌘ on macOS and Ctrl on Windows. The full list is also under the keyboard button in the top bar.

| Shortcut | Action |
| --- | --- |
| Mod+S | Save project |
| Mod+Z / Mod+Shift+Z | Undo / redo |
| Mod+K | Find node, chapter or asset |
| Mod+P | Preview |
| Mod+E | Export game |
| Mod+J | AI assistant |
| Mod+, | Settings |
| Tab | Add node (story graph) |
| Delete | Delete selection |
| Mod+C / Mod+V | Copy / paste |
| Mod+D | Duplicate |
| Mod+A | Select all (story graph) |
| F | Frame all / selection |
| Enter | Open selected node |
| Shift+drag | Box select |
| Space+drag | Pan the canvas |
| Wheel | Zoom |
| Mod+G | Group layers |
| Arrow keys | Nudge layer (Shift ×10) |
| , and . | Previous / next keyframe |

The timeline has its own After Effects-style shortcuts (J / K, I / O, B / N, M, U, G, F9…): see [Animation → Shortcuts](animation.md#shortcuts-timeline-focused).
