# 游戏模块：继承、全局元素、角色帧、列表与收集品

0.3.0 把页面变成了一个小型游戏引擎。本页包括：

- **页面之间的继承**：故事继续时哪些东西会接着运行。
- **全局页面**：所有页面都有的元素。
- **元素变量**：带帧的角色和参数。
- **列表和标签**。
- **收集品**：玩家拾取、之后使用的物品。

[English](game-module.md)

## 继承：哪些东西会延续到下一个页面

故事离开一个页面时，**仍在运行**的东西会延续到下一个页面：

| 正在运行的 | 延续方式 |
| --- | --- |
| 正在播放的音频或视频（自动播放 + 循环，或由脚本播放） | 声音继续，不会重新开始 |
| 被**循环**动画（自动播放）驱动的元素 | 元素和动画从原来的位置继续 |
| **循环**（*重复执行*）、计时器（*每隔 n 秒*）或*当鼠标进入*脚本 | 脚本在新页面重新开始，连同它使用的元素 |
| 这个页面自己继承来的元素和脚本 | 继续传到下一个页面 |

在新页面的**图层**面板里，这些元素列在**继承**下，并显示来源页面，以及 ▶（运行中）或 ⏸（已暂停）标记。它们的积木出现在**交互 → 元素 → 继承**里，新页面的脚本可以使用。双击继承的行可以回到原页面编辑这个元素。画布上也会画出继承和全局元素，画布工具栏的 🌐 按钮可以隐藏它们。

两个积木（*游戏*分类）决定页面切换时的行为。放在页面的任意脚本中即可；元素留空表示*这个脚本*：

- **当跳转页面删除 [元素]**：元素不会延续，媒体停止。元素留空时，这个脚本本身留在原页面。
- **当跳转页面停止 [元素]**：元素会延续，但处于**暂停**状态。它仍然列在下一个页面和交互里，但媒体、动画和帧播放停在原处。用**恢复 [元素]**让它继续；元素留空时，恢复这个页面上所有暂停的东西。**暂停 [元素]** 和 **[元素] 已暂停** 在任何页面都可以用。

规则：

- 背景音乐通道上的音乐会被下一个页面自己的音乐替换，和以前一样。
- 只有仍在运行的东西会被继承：已经播完的声音、不循环的动画都会留在原页面。
- 组会带上组内的内容。
- 回到某个页面时，这个页面自己的元素重新开始，不会从它继承。

*Like Human* 示例：*Rooftop* 的雨声在下一个天台页面里还能听到。那个页面在故事进入室内前用 *当跳转页面删除 Rain* 让雨声停下。*Memory* 用同样的方法删除旧电视。

## 全局页面

**剧情 → 全局（所有页面）** 打开全局页面，编辑方式和普通页面一样：

- **它的元素出现在所有页面**。可以用来放背景音乐、界面、背包、血条、静音按钮……
- **它们的状态共享**：在一个页面隐藏、移动或修改，到下一个页面仍然保持。
- **它的脚本在每个页面运行**，每个页面重新开始。

也可以在任何地方创建全局元素：

- **添加元素 → 全局元素**；
- **交互 → 游戏 → 新建… → 全局元素**；
- 在图层右键菜单里选择**设为全局**。这会移动元素并保留 id，所以脚本照常工作。

全局元素画在每个页面元素的前面。全局背景可以在检查器里设置 **层 → 在页面元素后面**。用**只放到这个页面**可以把全局元素移回单个页面。

## 元素变量

每个元素也是脚本可以使用的变量。**交互 → 游戏**里的**元素变量**列表包含这个页面的、继承的和全局的元素。双击（或双击*元素*里的药丸）打开编辑窗口。在那里可以：

- 改名；
- 在相近类型之间**更改类型**：图片 ↔ 角色（帧动画）↔ 背景、文字 ↔ 按钮、检测框 ↔ 形状；
- 选择媒体、区域形状或文字；
- 编辑**帧**（角色）和**参数**。

### 角色（帧动画）

用 **添加元素 → 游戏 → 角色（帧动画）** 或 **游戏 → 新建… → 角色** 创建角色。编辑窗口里有：

- 动画**预览**；
- **帧**：可以从素材库、图片文件或页面上的图片元素添加，可以调整顺序、复制、删除，把图片拖到某一帧上可以替换它；
- 速度、循环和*开始时播放*。

积木：

| 积木 | 作用 |
| --- | --- |
| [角色] 显示第 (n) 帧 | 停下并显示第 *n* 帧（从 1 开始） |
| 以每秒 (fps) 帧播放 [角色] | 正向播放（角色设为循环时循环） |
| 以每秒 (fps) 帧倒放 [角色] | 反向播放 |
| 以每秒 (fps) 帧播放 [角色] 一遍并等待 | 从第 1 帧播放到最后，然后继续脚本 |
| 停止 [角色] | 停在当前帧 |
| 将 [媒体] 加入 [角色] 的第 (n) 帧 | 把图片元素的图片（或另一个角色的当前帧）插入到第 *n* 帧；留空 = 放在最后一帧后面 |
| [角色] 的当前帧 / 帧数 | 数值 |
| 当 [角色] 播放到最后一帧 | 事件（不循环播放时） |

### 参数

任何元素都可以带自己的数值：**检查器 → 参数**，或在元素编辑窗口里添加。每个参数有名称、类型（数字、文本、是/否）和初始值，例如 *hp*、*speed*、*score*。使用方式：

- **将 [元素] 的 [参数] 设为 ( )**；
- **将 [元素] 的 [参数] 增加 ( )**；
- 数值 **[元素] 的 [参数]**，可以放在任何需要数字的地方，例如 *将 HUD 的 hp 增加 (Enemy 的 damage)*。

全局元素的参数在页面之间保留。

## 全局变量和列表

变量在所有页面之间共享。在 **交互 → 游戏 → 全局变量** 里：

- 把变量拖到积木空位上使用它的值；
- 双击变量可以修改名称、**类型**（数字、文本、是/否、**列表**）、记忆范围和初始值。

**列表**可以存多个值。列表积木在*变量*分类里：

- 加入、在第 n 项插入、替换、删除第 n 项、移除某个值、清空；
- 第 n 项、位置、项目数、包含？

位置从 1 开始，也可以写 *last*（最后）和 *random*（随机）。表达式里可以用 `item(bag, 1)`、`length(bag)`、`count(bag, "Coin")`、`contains(bag, "Key")`。文字中的列表显示为 `a, b, c`。

**标签**把数值显示在屏幕上：

- **在 x ( ) y ( ) 显示 ( )，标签 [名称]，字号 ( )**：在指定位置显示一个值，并实时跟随它变化，可以用来做血量、分数或计时器。同一个标签名会更新原来的标签。
- **在 x y 显示 [列表]**：每行显示一项。
- **隐藏标签 [名称]**：名称留空时隐藏所有标签。

全局脚本显示的标签会保留在所有页面。

## 变换积木

*游戏*分类里的元素变换积木：

- 旋转、设定角度、在 n 秒内转到某个角度；
- 移动 x/y、滑动 x/y；
- 大小增加 %、在 n 秒内缩放到 %；
- 透明度增加；
- 淡入、淡出（带渐变的显示和隐藏）；
- 水平翻转、垂直翻转；
- 移到最前、移到最后；
- 数值 *[元素] 的角度*。

## 收集品

设计思路：玩家在某些页面**收集**东西，之后**使用**它们，可以触发元素上的反应、解锁选项或走另一条路线。整个系统分五部分。

1. **物品**（*变量与角色 → 收集品*，或 *游戏 → 新建… → 新建物品*）：每个物品有名称和图标。创建第一个物品时会自动创建列表变量**背包**（inventory）。这个列表保存收集到的物品名称（重复的会计数），所以所有列表积木和表达式都能用在背包上。
2. **收集**：
   - **拾取 [元素] 作为 [物品]**：隐藏元素、加入物品，并记住这件事，再次回到这个页面时元素仍然消失。物品留空时使用元素的名字。
   - **将 (n) 个 [物品] 放入背包**：不通过元素直接加入物品。
   - **当收集到 [物品]**：在收集时做出反应。
3. **背包元素**（*添加元素 → 游戏 → 背包*，通常放在全局页面）：用网格显示收集到的物品，带图标和数量，玩家点击可以**选中**物品。
4. **把物品用在元素上**：
   - **当 [物品] 被用在 [元素] 上**：玩家先选中物品，再点击元素时触发。
   - 在里面可以用 **从背包拿走 (n) 个 [物品]**，也可以显示东西、修改变量或继续剧情。
   - **选中 [物品]**、*选中的物品*、*选中了 [物品]* 在脚本里也能用。
5. **需要物品的选项**：在选项的检查器里设置：
   - **需要物品**：只有带着这个物品时才能选择。*不可用时* 决定选项是隐藏还是显示为禁用。
   - **用掉物品**：选择后拿走这个物品。
   - 条件里也可以写 `has("Key")`。选项就是剧情端口，所以物品可以打开不同的路线。

拾取过的元素、选中的物品和全局元素都会随存档保存。

*Like Human* 示例：

- 旧照片放在 *Rooftop* 页面，点击即可拾取，右上角的全局背包随之淡入。
- 到了 *Memory*，选项*把旧照片给她*只有带着照片时才可选；选择后照片被用掉、好感度提升，走向 *Dawn* 结局。
- *Boot sequence* 页面有一个三帧的角色：状态灯。
