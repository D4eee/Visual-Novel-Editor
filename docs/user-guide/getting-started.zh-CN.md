# 快速上手

跟着这篇做一个有两条路线的小故事，预览它，再导出成游戏。整个过程大约十分钟。

## 1. 安装与启动

从 [Releases 页面](https://github.com/D4eee/Visual-Novel-Editor/releases)下载：

- **macOS 桌面版**：解压 `…-mac-arm64.zip`（Apple 芯片）或 `…-mac-x64.zip`（Intel），把 *Visual Novel Editor.app* 拖进「应用程序」。这个版本没有经过苹果公证，第一次打开前在「终端」运行一次：`xattr -cr "/Applications/Visual Novel Editor.app" && codesign --force --deep --sign - "/Applications/Visual Novel Editor.app"`，之后像普通应用一样双击打开。
- **Windows 桌面版**：解压 `…-win-x64.zip`，运行 *Visual Novel Editor.exe*。
- **Web 版**：解压 `…-web.zip`，双击 *Start Visual Novel Editor.command*（macOS）或 *start-windows.bat*（Windows），编辑器会在浏览器里打开；需要 Node.js 20 以上。
- **从源码运行**：`npm install`，然后 `npm start`（见仓库首页 README）。

桌面版内置示例游戏、示例模组和导出游戏所需的全部文件，可以离线使用。在首页「打开」示例时，打开的是你自己的副本，原示例不会被改动。

界面语言默认跟随系统（中文或英文），随时可以用右上角的语言按钮切换。

## 2. 新建项目

在首页点「新建项目」，填写名称、选择存放位置。编辑器会创建这样一个文件夹：

```
我的故事/
  project.vne.json   ← 整个故事（带版本号的 JSON 文件）
  assets/            ← 导入的图片、音频、视频、字体
  modules/           ← 这个项目用到的模块
  .vne/              ← 自动保存和备份（不用管它）
```

新项目里已经有一个章节、一个「开始」节点和第一个场景。

想先看看完整的例子？首页的「示例」里有 *Like Human*，用到了几乎所有功能。点「复制为新项目」就能得到一份可以随便改的副本。

## 3. 编写第一个场景

1. 在流程图里双击场景节点（或者选中后按 **Enter**），场景会在新标签页里打开。
2. 打开左侧的「素材」，把一张背景图和一张角色图拖到面板上导入。
3. 把背景素材拖到画布上，它会成为背景图层。
4. 打开「变量与角色」，点「添加角色」，起个名字、选个颜色，再「添加表情」并选用刚才的角色图。回到场景，「添加图层」→「角色立绘」，选择这个角色。
5. 「添加图层」→「对白」，在右侧检查器里输入一句台词。**Enter** 新建下一句，**Tab** 切换说话人。
6. 「添加图层」→「选项」两次，在检查器里把文字改为「往左走」和「往右走」，再在画布上摆好位置。

每个选项都会在场景节点上生成一个独立的输出端口。

## 4. 分支

回到章节标签页。从「往左走」端口拖出一条线，松开在空白处，选择「场景」，就会新建一个已经连好的场景。「往右走」同样操作。两条路线最后各接一个「结局」节点。

编辑时，底部状态栏会实时显示问题（比如某个输出没有连到任何地方）。点击状态栏打开问题列表，点某个问题就能跳到对应位置。

## 5. 预览

点「预览」（或 **Ctrl/⌘+P**）。预览使用的运行时和导出的游戏完全相同。「预览」旁边的箭头可以选择从哪里开始：当前场景、本章开头或游戏开头。右侧调试面板显示所有变量（运行中也可以修改）、走过的路径和事件记录。

## 6. 导出

点「导出」，选择平台（macOS Apple 芯片 / Intel、Windows、网页）和输出文件夹，再点「导出」。导出某个平台时会使用编辑器自带的运行时；如果你的编辑器版本没有附带，第一次导出该平台时会自动下载一次。签名相关的说明见[导出游戏](export.md)（英文）。

## 0.3.1 小贴士

- 开始界面里，右键最近项目可以**删除项目**（确认后移到废纸篓）。示例项目是图标，鼠标停留 2 秒会显示详细信息和“复制为新项目”。
- 所有报错和警告都在窗口底部的**控制台**里：点击左下角的“0 个错误 · 1 个警告 ▲”打开。
- 预览运行时，顶部的“预览”按钮会变成红色的**停止**按钮。
- **添加图层 → 文字 → 自由对白**：可以自己摆放的对白框，形状、背景、字体、名牌、气泡尾巴和打字效果都能改，也能在时间轴上做动画、在交互里用“说”积木控制。
- 每个字体选项旁边都有**上传**按钮，可以导入自己的 .ttf / .otf / .woff 字体。
