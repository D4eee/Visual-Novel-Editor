# 角色：骨骼、动作与表情

[English](characters.md) · **简体中文** · [用户指南](README.zh-CN.md)

角色不只是一组立绘。在**角色工作室**中，可以给角色制作由图片部件组成的骨骼、动作和表情。舞台上的角色元素会播放它们，由时间轴和交互决定何时播放什么。

可以用以下任一方式打开工作室：

- **数据面板：**展开某个角色，点击**角色工作室**。
- **属性栏：**选中角色元素，点击**编辑骨骼、动作和表情…**。
- **命令面板（Ctrl/⌘+K）：**运行“角色工作室：\<名称\>”。

左侧是预览，右侧是四个标签页。所有修改都可以撤销；点击**完成**或按 Esc 关闭。

## 骨骼

骨骼是由**骨头**组成的树，图片**部件**挂在骨头上。骨头移动或旋转时，它的子骨头和部件会跟着动。

有三种方式开始制作骨骼：

- **从立绘开始：**在脚底建立根骨骼和身体骨骼，并用立绘生成一个部件。
- **空骨骼：**在 600 × 900 的范围内建立一根根骨骼。
- **导入页：**从 Spine 或分层图片导入（见[导入](#导入)）。

编辑骨骼：

- **选中：**在预览中点击关节（圆形手柄）或部件，或在**骨骼**、**部件**列表中选择。
- **移动或旋转：**在预览中拖动可移动所选对象，按住 Shift 拖动可旋转；也可以直接输入位置、旋转、缩放和长度。
- **骨骼：****+** 会为所选骨骼添加子骨骼；删除骨骼时，它的子骨骼和部件会交给它的父骨骼。
- **部件：**图片按钮可从图片素材添加部件。列表按绘制顺序排列，最上面的在最前，用箭头调整顺序。
- **一个部件多张图片：**例如睁眼／闭眼或不同口型，用**添加图片**加入；单选按钮决定静止时显示哪一张。
- **尺寸与原点：**角色绘制所在的范围，以及对准元素位置的那个点（通常是脚底）。

## 动作

动作分为两种：

| 类型 | 说明 |
| --- | --- |
| **骨骼动作** | 骨头（移动、旋转、缩放）和部件（显示哪张图片、不透明度）的关键帧，可设缓动 |
| **序列帧** | 按设定的每秒帧数逐帧播放图片 |

**为骨骼动作打关键帧：**

1. 选中动作，再选中一根骨头或一个部件。
2. 拖动预览下方的播放头。
3. 拖动关节（按住 Shift 为旋转），或修改关键帧数值，就会在播放头处写入关键帧。

数值旁的 ◆ 按钮可添加或删除关键帧。点击关键帧时间可跳转；右键可修改缓动或删除。

动作中骨头的移动和旋转叠加在静止姿势上，缩放则相乘，所以调整静止姿势后动作依然适用。

**待机与循环：**

- **待机动作：**没有其他动作时会播放它。
- **一次性动作：**不循环的动作结束后会回到待机。
- **速度：**角色元素的**动作速度**可让动作播放得更快或更慢。

## 表情

表情可以改变部件的样子：

- **图片和不透明度：**更换每个部件的图片和不透明度（例如闭眼、脸红部件完全显示）。
- **细微姿势：**选中骨头后拖动或输入偏移。
- **没有骨骼时：**表情可以指定一张立绘，简单角色也能使用同一套表情。

表情和动作可以叠加：角色可以一边生气一边挥手。

## 导入

- **Spine：**在 Spine 3.8 或 4.x 中导出 JSON 并打包贴图图集，然后同时选择 `.json`、`.atlas` 和所有贴图图片。
  - **可导入：**骨骼、插槽及其图片、图片切换、移动、旋转、缩放和淡入淡出。动画会变成动作，名为 *idle* 的动画会成为待机动作。
  - **简化处理：**网格显示为平面图片。
  - **会忽略：**斜切、IK 等约束、绘制顺序和变形时间线，以及默认皮肤以外的皮肤。工作室会列出被忽略的内容。
  - **再次导入：**会替换骨骼和骨骼动作，序列帧动作会保留。
- **序列帧：**选择各帧图片（`walk_01.png`、`walk_02.png`…），按文件名排序后成为一个循环动作。
- **从分层图片创建部件：**按图层导出且尺寸相同的图片（身体、头发、眼睛…）会叠放在根骨骼上作为部件；之后再添加骨骼，并把各部件挂到对应骨骼。

不支持 Live2D（`.moc3`）模型。想要 Live2D 式的呼吸、眨眼和摇摆，可以用骨骼加图片切换和轻柔的循环动作来实现。

## 在舞台上

角色元素有骨骼（或序列帧）时就会显示它们。它的**选项**中有：

- **动作：**播放的动作；留空则播放待机动作。
- **表情：**显示的表情。
- **动作速度：**播放快慢。
- **显示方式：**“有骨骼或动作时使用它们”或“只显示立绘”。

这些属性可以由时间轴或交互控制：

- **时间轴：**像其他属性一样为**动作**打关键帧，每个关键帧都会在该时间让动作从头开始；**表情**也可以打关键帧。
- **交互：****播放动作**积木让元素播放某个动作（勾选“等待结束”则播放完才继续），**设置表情**积木更换表情。

导出的游戏只会包含骨骼用到的图片。

## 角色预设库

用**保存到预设库**把角色保存到你的**预设库**。工作室、数据面板，以及属性栏**预设**标签的**角色**区都有这个按钮。

预设库保存在你的用户文件夹中，所有项目都能使用：

- **添加到项目：**添加角色副本并导入它的图片。
- **用于此元素：**选中角色元素时，添加角色并让该元素显示它。

整套布景见[场景与图层 → 预设库中的场景](scenes.md#scenes-in-your-library)（英文）。
