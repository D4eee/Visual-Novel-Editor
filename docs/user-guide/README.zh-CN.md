## 认识工作区

| 区域 | 用途 |
| --- | --- |
| **顶部工具栏** | 项目标签、撤销与重做、预览范围、导出、模块、项目设置和界面语言 |
| **左侧栏** | 故事大纲、素材、变量、角色，以及模块添加的面板 |
| **中央工作区** | 在不同标签中打开章节流程图、场景画布与节点逻辑 |
| **底部面板** | 编辑场景时间轴与可视化脚本；通过测试功能查看脚本执行过程 |
| **属性面板** | 调整选中节点、元素或其他对象的属性 |
| **状态栏与控制台** | 查看保存状态、项目位置，以及按节点分组的问题；支持严重程度和文字筛选 |

将鼠标短暂停留在控件或字段名称上可查看提示。在画布上滚动鼠标滚轮可以缩放，拖动空白处可以平移。

使用 **Ctrl/⌘+Z** 撤销，使用 **Ctrl/⌘+Shift+Z** 重做。
