# Settings

Open **Settings** with the ⚙ button in the top bar (⌘/Ctrl+,). The window has these sections:

| Section | What it holds | Saved in |
| --- | --- | --- |
| **Project** (when a project is open) | Game title, description, resolution, text speed, default transition, title screen, text box style and font | the project |
| **General** | Interface language; save the project automatically (and after how long); number of undo steps; reset all editor settings | this computer |
| **Appearance** | Theme (Dark, Midnight, Dim, Warm), your own **background color** (panels are tinted from it), **accent color**, **font size**, **interface size** (zoom), interface font, what is shown around the stage, fewer interface animations | this computer |
| **Editing** | Ease of new keyframes, timeline time as seconds or timecode, frames per second (frame stepping and timecode), snapping on the canvas by default | this computer |
| **AI assistant** | Model service and API key, model, address, longest reply, what the assistant may do, and the list of editor tools — see [AI assistant](ai-assistant.md) | this computer (keys encrypted) |

Editor settings apply at once. A recovery copy of an open project is kept every 15 seconds whether or not automatic saving is on.
