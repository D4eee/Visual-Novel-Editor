# Visual Novel Editor 1.0.0

[English](#english) · [简体中文](#简体中文) · [Download this release](https://github.com/D4eee/Visual-Novel-Editor/releases/tag/v1.0.0)

## English

Version 1.0 adds an AI assistant that works on your project, a settings window, an After Effects-style timeline, presets in the inspector, and puzzle-shaped scripting blocks.

### Added

**AI assistant**

Open the chat panel with the **✦ AI** button next to the tab bar's **+** (Ctrl/⌘+J). It slides in from the right.

- **Models:** connect your own API key in **Settings → AI assistant**. You can use **Claude** (Anthropic) or any **OpenAI-compatible** service: OpenAI, DeepSeek, Kimi, Qwen, Zhipu GLM, OpenRouter, a local Ollama, or a custom address.
- **Working on your project:** the assistant edits the project through 24 editor tools, described in the Model Context Protocol (MCP) tool format. It can:
  - read the project and its scenes;
  - create and connect scenes;
  - add characters and variables;
  - write dialogue lines and choices;
  - add and edit elements, and set parent links;
  - add keyframes and animation presets, looks and effects;
  - build interaction scripts and change project settings.
- **Undo:** every change is an undo step, and **Undo this reply** reverses a whole answer.
- **Read-only mode:** the assistant only reads the project and answers.
- **Keys:** your key stays on this computer (encrypted with the system keychain in the desktop app) and is sent only to the service address it was saved for.

**Settings window**

Open it with Ctrl/⌘+,.

- **General:** interface language, automatic saving, undo steps.
- **Appearance:**
  - four themes;
  - your own background and accent colors;
  - font size, interface zoom and interface font;
  - what is shown around the stage;
  - fewer interface animations.
- **Editing:** default ease for new keys, seconds or timecode, frame rate, snapping.
- **AI assistant** settings, and the **project** settings.

**After Effects-style timeline**

- **Layer bars:** each element has a bar with **in and out points**. Outside its bar the element is hidden while the animation plays. Moving a bar moves the element's keys with it.
- **Property groups:** properties are grouped (Transform, Size, Text, Style, Effect). Each property has:
  - a **stopwatch**;
  - a value you can drag;
  - a **◀ ◆ ▶** keyframe navigator.

  Press **U** to show only animated properties.
- **Graph editor (G):** value curves with draggable keys and **bezier handles**.
- **Editing keys:**
  - box selection, and **Alt-drag** to stretch keys in time;
  - snapping to the playhead, keys, markers and in/out points;
  - **markers (M)** and a **work area (B / N)**;
  - frame stepping, J / K to jump between keys, F9 for easy ease.
- **Parent & link:** an element follows another element's position, rotation and scale, and stays in place when linked.
- **Motion paths:** shown on the canvas, with position keys you can drag.

**Options, Effects and Presets tabs**

Selecting an element shows three tabs at the top of the inspector.

- **Effects:** the element's effect, effect presets and blending.
- **Presets:**
  - 18 animation presets (entrance, emphasis, exit), written as keyframes at the playhead;
  - looks for text, shapes, buttons and free dialogue boxes;
  - your own saved looks, shared across projects.

### Improved

- **Puzzle-shaped blocks:** interaction blocks interlock like Scratch, with a notch on top and a bump below.
  - Triggers have a round top.
  - *Stop*, *Go to scene*, *Continue* and *Forever* have a flat bottom, so nothing can be attached after them; these blocks fit only at the end of a script.
  - C-shaped blocks also look like C shapes in the palette.
- **New application icon** in the app, its windows, the taskbar, the start screen, the top bar and on GitHub.
- **Web edition:** the release now includes the web edition archive.
- **Safer local web API:** the browser editor's local API accepts requests only from the editor page.

### Compatibility

- **Project format 4.** Older projects are upgraded when opened. Earlier editors cannot open projects saved by 1.0.
- **Module API 1.3:**
  - `BlockDef.endsScript`;
  - `Layer.link`;
  - animation in/out points (`AnimationClip.spans`), markers and the work area.
- **Engine range:** modules whose manifest limits the engine to `<1.0.0` are marked incompatible. Widen the range after checking them. The example modules now use `<2.0.0`.

### Installation

**macOS:** Extract the archive and move `Visual Novel Editor.app` to Applications. The app is not Apple-notarized. For a build you trust, follow the existing first-launch procedure:

```bash
xattr -cr "/Applications/Visual Novel Editor.app"
codesign --force --deep --sign - "/Applications/Visual Novel Editor.app"
```

**Windows:** Extract the archive and open `Visual Novel Editor.exe`. If SmartScreen appears, the existing launch procedure is **More info → Run anyway**, provided you trust the build.

**Linux:** Extract the archive and run `visual-novel-editor`.

**Web editor:** Extract the archive and start it with Node.js as described in its README, then open the editor in your browser.

## 简体中文

1.0 版加入了可以直接操作项目的 AI 助手、设置窗口、类似 After Effects 的时间轴、属性面板中的预设，以及拼图形状的交互积木。

### 新增功能

**AI 助手**

点击标签栏 **+** 旁边的 **✦ AI**（Ctrl/⌘+J），聊天面板会从右侧滑出。

- **模型：**在 **设置 → AI 助手** 中填写你自己的 API Key。支持 **Claude**（Anthropic），以及所有 **OpenAI 兼容接口**：OpenAI、DeepSeek、Kimi、通义千问、智谱 GLM、OpenRouter、本地 Ollama 或自定义地址。
- **直接操作项目：**助手通过 24 个编辑器工具修改项目，这些工具按 Model Context Protocol（MCP）的工具格式描述。它可以：
  - 读取项目和场景；
  - 新建并连接场景；
  - 添加角色和变量；
  - 编写对白和选项；
  - 添加、修改元素，设置父级；
  - 添加关键帧和动画预设、外观和效果；
  - 搭建交互脚本，修改项目设置。
- **撤销：**每次修改都在撤销历史中，**撤销这次修改** 可以一键撤回整条回复。
- **只读模式：**助手只读取项目并回答。
- **Key 的保存：**Key 只保存在本机（桌面版使用系统钥匙串加密），并且只会发送给保存它时的那个服务地址。

**设置窗口**

按 Ctrl/⌘+, 打开。

- **通用：**界面语言、自动保存、撤销步数。
- **外观：**
  - 4 种主题；
  - 自定义背景色和强调色；
  - 字体大小、界面缩放和界面字体；
  - 舞台周围背景；
  - 减少界面动画。
- **编辑：**新关键帧的默认缓动、时间显示为秒或时间码、帧率、默认吸附。
- 另有 **AI 助手** 和 **项目设置**。

**After Effects 风格时间轴**

- **图层条：**每个元素有一条图层条，可以设置 **入点和出点**。动画播放时，图层条以外的时间元素不显示。拖动图层条会连同它的关键帧一起移动。
- **属性分组：**属性按“变换 / 尺寸 / 文字 / 样式 / 效果”分组。每个属性有：
  - **秒表**；
  - 可拖动的数值；
  - **◀ ◆ ▶** 关键帧导航。

  按 **U** 只显示有动画的属性。
- **图表编辑器（G）：**显示数值曲线，可以拖动关键帧和 **贝塞尔手柄**。
- **编辑关键帧：**
  - 框选关键帧，按 **Alt 拖动** 按时间拉伸；
  - 吸附到播放头、关键帧、标记和入出点；
  - **标记（M）** 和 **工作区（B / N）**；
  - 逐帧移动，J / K 跳到上一个 / 下一个关键帧，F9 缓入缓出。
- **父级链接：**元素跟随另一个元素的位置、旋转和缩放，设置时保持在原位。
- **运动路径：**显示在画布上，可以直接拖动位置关键帧。

**选项 / 效果 / 预设标签**

选中元素后，属性面板顶部有三个标签。

- **效果：**元素的效果、效果预设和混合模式。
- **预设：**
  - 18 个动画预设（入场、强调、退场），按关键帧写在播放头处；
  - 文字、形状、按钮和自由对白框的外观；
  - 可以跨项目使用的“我的预设”。

### 体验改进

- **拼图形状的积木：**交互积木像 Scratch 一样拼接，上有凹口、下有凸起。
  - 触发积木顶部是圆的。
  - “停止脚本”“跳转场景”“继续”和“重复执行”底部是平的，后面不能再接积木；这些积木只能放在脚本末尾。
  - C 形积木在积木面板里也显示为 C 形。
- **新版应用图标：**应用、窗口、任务栏、开始界面、顶栏和 GitHub 都已更换。
- **网页版下载：**发布附件中增加了网页版编辑器压缩包。
- **本地网页版接口更安全：**浏览器版的本地接口只接受编辑器页面发出的请求。

### 兼容性

- **项目文件格式 4。**旧项目打开时会自动升级；更早版本的编辑器无法打开 1.0 保存的项目。
- **模组 API 1.3：**
  - `BlockDef.endsScript`；
  - `Layer.link`；
  - 动画入出点（`AnimationClip.spans`）、标记和工作区。
- **引擎版本范围：**清单中把引擎版本限制为 `<1.0.0` 的模组会被标记为不兼容，检查后放宽范围即可。示例模组已改为 `<2.0.0`。
