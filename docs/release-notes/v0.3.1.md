## Visual Novel Editor 0.3.1

### 新功能 / New
- **自由对白 / Free dialogue**：可自由摆放和设计样式的对白框——位置、形状（圆角、矩形、胶囊、椭圆、带尾巴的气泡、思考泡、无）、填充/渐变/描边/阴影、文字与名字的全部样式、打字机效果，可做关键帧变换；新增“说…作为…等待”和“当…打字完成时”积木。
  A dialogue box you place and style freely: shapes, fill/gradient/outline/shadow, full text and name styling, typewriter, keyframes; new "says … as … wait" and "when … finishes typing" blocks.
- **自定义字体 / Your own fonts**：每个字体选项都可以上传 ttf/otf/woff/woff2，画布、预览和导出的游戏里都会使用。
  Upload ttf/otf/woff/woff2 in any font field; used on the canvas, in previews and in exported games.
- **底部控制台 / Bottom console**：所有报错移到从左下角状态文字向上展开的控制台（按节点分组、按严重程度和文字筛选、可调整高度）。
  Problems live in a VS Code-like console that slides up from the status bar.
- **预览 / Preview**：预览时顶部的运行按钮变成红色“停止”。The Preview button turns into a red Stop while running.
- **开始界面 / Start screen**：右键最近项目可打开、在文件夹中显示、从列表移除或删除（确认后移到废纸篓）；示例项目以 App 图标显示在 3 列可滚动的方框里，悬停 2 秒显示详情。
  Right-click a recent project to delete it (after confirmation); examples shown as app icons with details on a 2 s hover.

### 修复 / Fixed
- 积木面板中换行的积木标签会和下一块重叠。Wrapped block labels no longer overlap the next block.

**macOS**：解压后把 `Visual Novel Editor.app` 拖到“应用程序”。应用没有 Apple 公证，第一次打开前在终端运行一次：
Unzip and drag the app to Applications. The app is not notarized; before the first launch run once in Terminal:

```
xattr -cr "/Applications/Visual Novel Editor.app"
```

**Windows**：解压后双击 `Visual Novel Editor.exe`。如果出现 SmartScreen 提示，点“更多信息 → 仍要运行”。
Unzip and run `Visual Novel Editor.exe`; on a SmartScreen prompt choose "More info → Run anyway".

**Linux**：解压后运行 `visual-novel-editor`。Unzip and run `visual-novel-editor`.

`SHA256SUMS.txt` 里有每个文件的校验值。`SHA256SUMS.txt` lists each file's checksum.
