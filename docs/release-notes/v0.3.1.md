# Visual Novel Editor 0.3.1

[English](#english) · [简体中文](#简体中文) · [Download this release](https://github.com/D4eee/Visual-Novel-Editor/releases/tag/v0.3.1)

## English

This release gives you more control over dialogue presentation, adds custom font imports, and makes previewing and diagnosing your project easier.

### Added

**Freely positioned dialogue boxes**

Design dialogue as part of the scene composition. Choose a rectangle, rounded rectangle, capsule, ellipse, speech bubble, thought bubble, or no box. Customize fills, gradients, outlines, shadows, speaker names, and text styles. Add typewriter reveals and animate transforms with keyframes.

New visual scripting blocks let a character speak and wait for the line to finish, or trigger an action when typing completes.

**Custom font imports**

Import TTF, OTF, WOFF, or WOFF2 files from font controls. Imported fonts are available on the scene canvas, in previews, and in exported games.

**Docked console**

Open the console from the lower-left status bar to review issues grouped by node. Filter by severity or text, and resize the panel to fit your workspace.

### Improved

- **Preview controls:** The top-bar Preview button becomes a red Stop button during playback.
- **Recent projects:** Right-click to open a project, reveal its folder, remove it from the recent list, or delete it after confirmation. Deleted projects are moved to the system Trash or the editor's trash folder, depending on the environment.
- **Example browser:** Examples appear in a scrollable, three-column icon grid. Hover for two seconds to see details.

### Fixed

- Wrapped labels in the scripting block palette no longer overlap the next block.

### Installation

**macOS:** Extract the archive and move `Visual Novel Editor.app` to Applications. The app is not Apple-notarized. For a build you trust, follow the existing first-launch procedure:

```bash
xattr -cr "/Applications/Visual Novel Editor.app"
codesign --force --deep --sign - "/Applications/Visual Novel Editor.app"
```

**Windows:** Extract the archive and open `Visual Novel Editor.exe`. If SmartScreen appears, the existing launch procedure is **More info → Run anyway**, provided you trust the build.

**Linux:** Extract the archive and run `visual-novel-editor`.

## 简体中文

本次更新扩展了对白的设计方式，加入自定义字体导入，并改善了项目预览与问题排查体验。

### 新增功能

**自由对白框**

将对白作为场景的一部分自由编排。可选择矩形、圆角矩形、胶囊、椭圆、对话气泡、思考气泡或无框样式，调整填充、渐变、描边、阴影、角色名和文字样式。支持逐字显示，并可通过关键帧制作变换动画。

新增可视化脚本积木，可让角色说出一句对白并等待显示完成，或在逐字显示结束时触发后续动作。

**自定义字体导入**

在字体控件中导入 TTF、OTF、WOFF 或 WOFF2 文件。导入的字体可用于场景画布、预览和导出的游戏。

**底部控制台**

点击左下角状态栏展开控制台，按节点集中查看问题，按严重程度或文字筛选，并根据工作区需要调整面板高度。

### 体验改进

- **预览控制：** 预览运行时，顶部“预览”按钮变为红色“停止”按钮。
- **最近项目管理：** 右键可打开项目、显示所在文件夹、从最近列表移除，或在确认后删除项目。根据运行环境，删除的项目会移入系统废纸篓或编辑器的回收目录。
- **示例浏览：** 示例以三列图标网格展示，支持滚动浏览；悬停两秒可查看详情。

### 问题修复

- 修复脚本积木面板中标签换行后与下一块积木重叠的问题。
