# Visual Novel Editor 1.1.1

[English](#english) · [简体中文](#简体中文) · [Download this release](https://github.com/D4eee/Visual-Novel-Editor/releases/tag/v1.1.1)

## English

Version 1.1.1 makes the editor easier to find your way in and gives the canvas more room. It adds a text box element, a text view of each scene, a command palette, a history panel and a first-run tour.

### Added

- **Text box element:** **Add layer → Text → Text box** adds a box whose text wraps to its size.
  - **Box:** size, padding, color, border and rounded corners.
  - **Text:** font, size, color, line height, typing reveal; left, center or right and top, middle or bottom alignment.
  - **Overflow:** text that does not fit is cut off, shrinks to fit, or runs past the box.
  - **Resizing:** dragging the handles resizes the box and the text re-wraps; hold Alt to scale instead.
  - **Typing on the canvas:** double-click a text or text box to type in it directly.
- **Script view:** the new **Script** tab of a scene shows its dialogue and choices as text, in the format of *Import a script*.
  - Edits apply as you type, one undo step per pause; changes made in the dialogue list or the graph show up in it too.
  - Lines and choices keep their identity, so translations and voices stay attached.
  - `* Choice -> Scene` and `-> Scene` connect the scene in the graph.
- **Command palette (Ctrl/⌘+K):** jump to any scene, chapter, element, character or asset, or run a command (new scene, preview, export, translations, settings, AI assistant…). Type `>` to list only commands.
- **History panel (🕘, Ctrl/⌘+Shift+H):** every step since the project was opened, including the AI assistant's; click one to go back or forward to it.
- **First-run tour:** six short tips the first time a project is open. Replay it from the command palette or the home screen.
- **First steps in empty scenes:** cards on the canvas add a background, a character, the dialogue or a text box, or open the Script view.

### Improved

- **Narrow windows:** when the window is narrow or the AI assistant is open, the left panel and then the inspector tuck away so the work area keeps its room. Their buttons open them over the work area; Esc closes them. The scene header no longer overlaps.
- **More room for the canvas:** hide the Layers list or the timeline dock from the scene header, or both with **Ctrl/⌘+\\**. A fitted canvas stays fitted when panels change.
- **Bigger preview:** while a preview runs, the inspector makes room for the game. The debug panel folds away, and an error count shows while it is hidden.
- **New projects:** default names follow the interface language (“第一章”, “开始”, “结局” in Chinese). A new project starts as Start → first scene → ending, so it opens without warnings.
- **Composition elements** choose their composition from a named list instead of showing its id.

### Compatibility

- **Project format 5**, unchanged from 1.1.0. Projects with text boxes need 1.1.1 to show them.
- **Module API 1.5:** the `composition` property type and the built-in `core.textbox` element. Modules for API 1.0–1.4 keep working.

### Installation

**macOS:** Extract the archive and move `Visual Novel Editor.app` to Applications. The app is not Apple-notarized. For a build you trust, follow the existing first-launch procedure:

```bash
xattr -cr "/Applications/Visual Novel Editor.app"
codesign --force --deep --sign - "/Applications/Visual Novel Editor.app"
```

**Windows:** Extract the archive and open `Visual Novel Editor.exe`. If SmartScreen appears, the existing launch procedure is **More info → Run anyway**, provided you trust the build.

**Linux:** Extract the archive and run `visual-novel-editor`.

**Web editor:** Extract the archive and start it with Node.js as described in its README, then open the editor in your browser.

## 简体中文

1.1.1 版让编辑器更容易上手，也给画布留出了更多空间。新增文本框元素、场景的剧本视图、命令面板、历史记录面板和新手引导。

### 新增功能

- **文本框元素：**通过**添加图层 → 文字 → 文本框**添加，框里的文字会按框的大小自动换行。
  - **框：**尺寸、内边距、颜色、边框和圆角。
  - **文字：**字体、字号、颜色、行高、打字效果；水平可左/中/右对齐，垂直可上/中/下对齐。
  - **放不下时：**可选择截断、自动缩小字号，或超出框外显示。
  - **调整大小：**拖动手柄会改变框的大小，文字随之重新排版；按住 Alt 则改为缩放。
  - **画布上直接输入：**双击文字或文本框即可直接打字。
- **剧本视图：**场景新增**剧本**标签，以文本形式显示对白和选项，格式与“导入剧本”相同。
  - 边输入边应用，每次停顿算一步撤销；在对白列表或流程图里的修改也会同步到这里。
  - 对白和选项保持原有身份，译文和语音不会丢。
  - `* 选项 -> 场景` 和 `-> 场景` 会在流程图里连好线。
- **命令面板（Ctrl/⌘+K）：**跳转到任意场景、章节、元素、角色或素材，或执行命令（新建场景、预览、导出、翻译、设置、AI 助手……）。输入 `>` 只看命令。
- **历史记录面板（🕘，Ctrl/⌘+Shift+H）：**列出打开项目以来的每一步，包括 AI 助手做的修改；点击即可回到或前进到那一步。
- **新手引导：**第一次打开项目时显示 6 条简短提示，可在命令面板或首页重看。
- **空场景快捷开始：**画布上的卡片可以直接添加背景、角色、对白或文本框，或切换到剧本视图。

### 体验改进

- **窄窗口：**窗口较窄或打开 AI 助手时，左侧栏和属性栏会依次收起，让工作区保持足够宽度；点它们的按钮可在工作区上方打开，Esc 关闭。场景标题栏不再重叠。
- **画布空间更大：**可在场景标题栏隐藏图层面板或时间轴面板，**Ctrl/⌘+\\** 一键全部隐藏或恢复；适应窗口的画布在面板变化后会自动重新适应。
- **预览更大：**预览时属性栏让出空间；调试面板可以折叠，折叠时会显示错误数量。
- **新项目：**默认名称跟随界面语言（中文为“第一章”“开始”“结局”）；新项目是“开始 → 第一个场景 → 结局”的完整流程，打开时不再有警告。
- **合成元素**改为从合成名称列表中选择，不再显示内部编号。

### 兼容性

- **项目文件格式 5**，与 1.1.0 相同。包含文本框的项目需要 1.1.1 才能显示文本框。
- **模组 API 1.5：**新增 `composition` 属性类型和内置的 `core.textbox` 元素。适用于 API 1.0–1.4 的模组可继续使用。
