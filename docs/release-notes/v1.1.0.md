# Visual Novel Editor 1.1.0

[English](#english) · [简体中文](#简体中文) · [Download this release](https://github.com/D4eee/Visual-Novel-Editor/releases/tag/v1.1.0)

## English

Version 1.1 makes games multi-language, imports scripts written as plain text, completes the player's features in exported games, lets the AI assistant see the canvas and draft images, and adds waveforms, expressions and precomposing to the timeline.

### Added

**Multi-language games**

Open **Translations** with the 文A button in the top bar.

- **Translation table:** every text players read, in one list:
  - dialogue lines, choices and character names;
  - text elements, speech bubbles and button labels;
  - texts shown by scripts, and the game's title and description.
- **Status:** filter by *Not translated*, *Changed* (the original was edited after translating) and *Translated*. Each language shows its progress.
- **AI translation:** **Translate with AI** uses the AI assistant's model, in batches, with the speaker and scene as context. Variables and tags are kept, and character names stay consistent.
- **Spreadsheets:** export a language as CSV, translate it in Excel, Numbers or Google Sheets, and import it back.
- **Preview a language:** choose it under *Preview language* in the Preview menu.
- **In the game:** the game starts in the player's language. Players switch language in **Settings**; texts without a translation show the original.

**Script import**

Write scenes as plain text and import them from the story graph (📄 in the graph toolbar).

- `## Scene` starts a scene; `# Chapter` starts a chapter.
- `Name: line` and `Name (portrait): line` are dialogue; other lines are narration. Chinese full-width colons and brackets work too.
- `* Choice -> Scene` adds a choice; `-> Scene` or `-> END` says where the scene goes. Scenes without either continue to the next one.
- `[bg: …]`, `[music: …]` and `[voice: …]` set the background, music and voice by asset name or color.
- A preview lists the scenes, new characters and anything that cannot be connected. Missing characters are created, and the whole import is one undo step.
- The AI assistant can import scripts as well.

**Player features in exported games**

- **Quick save and quick load:** Q.Save / Q.Load buttons, F5 / F9.
- **Skip stops at unread text:** read lines are remembered across plays. *Skip unread text too* in Settings skips everything.
- **Voice in the log:** ▶ replays a line's voice.
- **Auto mode waits for voices** to finish (it can be turned off in Settings). A new line's voice stops the previous one.
- Already there and unchanged: save and load with thumbnails, autosave, the log, auto, skip and volume settings.

**AI assistant**

- **It can see the canvas:** 📷 attaches a picture of the open scene to your message. The assistant can also look by itself with the new *view scene* tool. This needs a model that accepts images.
- **New tools:** *view scene*, *import script* and *generate image*.

**Image generation**

Draft backgrounds and character sketches from the Assets panel (**Generate images**).

- **Services:** set them up in **Settings → Image generation**:
  - **OpenAI format**: `gpt-image-1`, `dall-e-3`, or any service with the same API, such as proxies offering Midjourney or Flux;
  - **Stability AI**: Core, Ultra, SD 3.5;
  - **Replicate**: Flux, SDXL and other models.
- **Kinds:** backgrounds match the stage shape; character sketches are portrait. Make 1–4 images at a time, add the ones you like to the assets, or use one as the open scene's background.
- **Keys:** stored like the AI assistant's: on this computer, encrypted where possible, and only sent to the service they were saved for.
- Midjourney has no official API: use it through an OpenAI-format proxy.

**Timeline**

- **Audio waveforms** in the timeline's media bars. Turn them off in *Settings → Editing*.
- **Expressions:** click **=** on a property row to set a formula:
  - `follow("Mika", 0.2)` follows another element with a delay;
  - `value + wiggle(2, 10)` adds a smooth random wobble;
  - `loop()` repeats the keys;
  - `sin(time * 3) * 20` swings back and forth.

  Expressions are formulas, not code: nothing else runs.
- **Precompose:** move elements and their animation into a reusable composition, from the Layers panel or the timeline.
  - Composition elements have *Starts at*, *Speed* and *Playback* (once, loop, back and forth).
  - Add a composition to any scene from **Add layer → Compositions**.
  - Unpacking and updating a composition keep its animation.

### Fixed

- **Parent links:** dragging a parent together with its children moved the children twice as far. It now moves them once.
- **Parent links:** deleting a parent no longer makes its children jump. They keep their place and follow the parent's own parent, if it has one.

### Compatibility

- **Project format 5.** Projects are upgraded when opened. Version 1.0 cannot open projects saved by 1.1.
- **Module API 1.4:**
  - `PropDef.translatable` and `BlockArgDef.translatable` put a module's texts into the translation table;
  - `Project.localization`; games play the translated copy, so modules read translated texts with no extra work;
  - `Composition.animation`, and `startAt`, `speed` and `playback` on composition elements;
  - `Track.expr`.
- Modules for API 1.0–1.3 keep working.

### Installation

**macOS:** Extract the archive and move `Visual Novel Editor.app` to Applications. The app is not Apple-notarized. For a build you trust, follow the existing first-launch procedure:

```bash
xattr -cr "/Applications/Visual Novel Editor.app"
codesign --force --deep --sign - "/Applications/Visual Novel Editor.app"
```

**Windows:** Extract the archive and open `Visual Novel Editor.exe`. If SmartScreen appears, the existing launch procedure is **More info → Run anyway**, provided you trust the build.

**Linux:** Extract the archive and run `visual-novel-editor`.

**Web editor:** Extract the archive and start it with Node.js as described in its README, then open the editor in your browser.

## 简体中文

1.1 版让作品支持多种语言，可以导入纯文本剧本，补齐了导出游戏里玩家常用的功能，让 AI 助手能看到画布并生成图片草稿，时间轴也加入了波形、表达式和预合成。

### 新增功能

**多语言作品**

点击顶部工具栏的“文A”按钮打开**翻译**。

- **翻译表：**玩家能看到的文字都在一张表里：
  - 对白、选项和角色名；
  - 文字元素、对话气泡和按钮文字；
  - 脚本显示的文字，以及作品标题和简介。
- **状态：**可筛选“未翻译”、“原文已改”（翻译后原文又被修改）和“已翻译”，每种语言都显示完成度。
- **AI 翻译：****用 AI 翻译**使用 AI 助手的模型分批翻译，并附上说话人和场景作为上下文；变量和标签保持不变，角色名前后一致。
- **表格：**可把某种语言导出为 CSV，在 Excel、Numbers 或 Google 表格里翻译后再导入。
- **预览语言：**在“预览”菜单的“预览语言”中选择。
- **游戏中：**游戏会按玩家的语言启动；玩家可在**设置**里切换语言，没有译文的文字显示原文。

**剧本导入**

用纯文本写场景，然后在流程图中导入（流程图工具栏的 📄 按钮）。

- `## 场景` 开始一个场景，`# 章节` 开始一个章节。
- `名字：台词` 和 `名字（立绘）：台词` 是对白，其他行是旁白；中英文冒号和括号都可以。
- `* 选项 -> 场景` 添加选项，`-> 场景` 或 `-> 结束` 指定场景之后去哪里；两者都没有的场景会接到下一个场景。
- `[bg: …]`、`[music: …]`、`[voice: …]` 按素材名或颜色设置背景、音乐和语音。
- 导入前会预览要创建的场景、新角色，以及无法连接的地方。缺少的角色会自动创建，整个导入是一步撤销。
- AI 助手也能导入剧本。

**导出游戏的玩家功能**

- **快速存档和快速读档：**快存 / 快读按钮，F5 / F9。
- **快进在未读文字处停下：**已读的对白会跨周目记住；在设置里勾选“快进时也跳过未读文字”可全部跳过。
- **回看中重播语音：**点击 ▶ 重播这句对白的语音。
- **自动模式会等语音播完**（可在设置中关闭）；新对白的语音会停止上一句。
- 原有功能不变：带缩略图的存档/读档、自动存档、对白回看、自动、快进和音量设置。

**AI 助手**

- **能看到画布：**点击 📷 可把当前场景的画面随消息发送，助手也能用新的“查看场景”工具自己查看。需要支持图片输入的模型。
- **新工具：**查看场景、导入剧本、生成图片。

**图片生成**

在素材面板中打开**生成图片**，生成背景和角色草图。

- **服务：**在**设置 → 图片生成**中设置：
  - **OpenAI 格式**：`gpt-image-1`、`dall-e-3`，或兼容同一格式的服务，例如提供 Midjourney、Flux 的中转；
  - **Stability AI**：Core、Ultra、SD 3.5；
  - **Replicate**：Flux、SDXL 等模型。
- **类型：**背景与舞台比例一致，角色草图为竖图。每次可生成 1–4 张，把喜欢的添加到素材，或直接设为当前场景的背景。
- **密钥：**与 AI 助手相同：保存在本机，尽可能加密，只发送给保存时对应的服务。
- Midjourney 没有官方 API，可通过 OpenAI 格式的中转使用。

**时间轴**

- 时间轴的媒体条上显示**音频波形**，可在“设置 → 编辑”中关闭。
- **表达式：**点击属性行的 **=** 设置公式：
  - `follow("Mika", 0.2)` 延迟跟随另一个元素；
  - `value + wiggle(2, 10)` 加上平滑的随机抖动；
  - `loop()` 循环关键帧；
  - `sin(time * 3) * 20` 来回摆动。

  表达式只是公式，不会运行其他代码。
- **预合成：**在图层面板或时间轴中，把元素连同动画打包成可复用的合成。
  - 合成元素有“开始时间”、“速度”和“播放方式”（一次、循环、往返）。
  - 可在任意场景中通过**添加图层 → 合成**使用。
  - 解包和更新合成时会保留它的动画。

### 问题修复

- **父级链接：**同时选中父元素和子元素一起拖动时，子元素会移动两倍距离；现在只移动一次。
- **父级链接：**删除父元素后，子元素不再跳位置；它们保持原位，并改为跟随父元素自己的父级（如果有）。

### 兼容性

- **项目文件格式 5。**旧项目打开时会自动升级；1.0 无法打开 1.1 保存的项目。
- **模组 API 1.4：**
  - `PropDef.translatable` 和 `BlockArgDef.translatable` 让模组的文字进入翻译表；
  - `Project.localization`；游戏运行的是翻译后的副本，模组无需额外处理就能读到译文；
  - `Composition.animation`，以及合成元素的 `startAt`、`speed`、`playback`；
  - `Track.expr`。
- 适用于 API 1.0–1.3 的模组可继续使用。
