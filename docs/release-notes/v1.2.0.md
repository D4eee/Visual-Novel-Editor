# Visual Novel Editor 1.2.0

[English](#english) · [简体中文](#简体中文) · [Download this release](https://github.com/D4eee/Visual-Novel-Editor/releases/tag/v1.2.0)

## English

Version 1.2.0 brings characters to life and adds a preset library shared by all your projects. Characters can have a skeleton of image parts, motions and expressions, built in the new Character studio or imported from Spine. Scenes and characters can be saved to the library and used anywhere.

### Added

- **Character studio:** open it from a character in the **Data** panel, from a character element (**Edit skeleton, motions and expressions…**) or from the command palette.
  - **Skeleton:** bones with image parts attached. Drag a joint or a part on the preview to move it; hold Shift to rotate. A part can hold several images (eyes open / closed, mouth shapes) and switch between them.
  - **Start quickly:** from the character's portrait, from an empty skeleton, or from layered images exported at the same size.
  - **Motions:** skeleton motions are keyframes of bones and parts (move, turn, scale, image, opacity, with easing). Image-sequence motions play frames. One motion is the **idle** motion; a motion that does not loop goes back to idle when it ends.
  - **Expressions:** change images and opacity of parts and nudge bones. Characters without a skeleton can use an expression to show a portrait.
- **Spine import:** choose the `.json`, the `.atlas` and the page images exported from Spine 3.8 or 4.x. Bones, image swaps, moves, turns, scales and fades come across. Meshes are drawn as flat images, and constraints are left out; the studio lists what was left out.
- **Character elements play motions:**
  - **Inspector:** new **Motion**, **Expression**, **Motion speed** and **Show** properties.
  - **Timeline:** key **Motion** to start a motion at a set time; each key starts its motion from the beginning.
  - **Interactions:** new blocks **Play motion** (optionally wait until it ends) and **Set expression**.
- **Preset library (your user folder, shared by every project):**
  - **Scenes:** in the **Presets** tab (with nothing selected, or with an element selected), **Save as scene…** saves the chosen elements with their animation keys and the interactions they start.
    - **Adding a scene** puts it in as one group above the backgrounds.
    - **Switching scenes** replaces the scene added before, so one click changes the set.
  - **Characters:** save a character with its portraits, skeleton, motions and expressions, then add it to any project, or use it on the selected character element.
  - **Files come along:** images and sounds are copied into the library, and into the project when you use an entry.

### Improved

- **Simplified Chinese:** portraits are now called 立绘 and the new expressions 表情.
- **Stacked windows:** a confirmation that opens over another window answers Esc and Tab on its own.

### Compatibility

- **Project format 6.** Older projects open without changes. Projects that use skeletons, motions or scene presets need 1.2.0.
- **Module API 1.6:**
  - Property types `motion` and `expression`.
  - `PropDef.clock`: the timeline also reports `<key>Since`.
  - `Character.rig`, `motions`, `expressions` and `defaultMotion`, and `Layer.presetGroup`.
  - Modules for API 1.0–1.5 keep working.

## 简体中文

1.2.0 版让角色动起来，并新增所有项目共用的预设库。角色可以拥有由图片部件组成的骨骼、动作和表情，可在新的角色工作室中制作，也可从 Spine 导入。场景和角色可以保存到预设库，在任何地方使用。

### 新增功能

- **角色工作室：**可从**数据**面板的角色、角色元素的**编辑骨骼、动作和表情…**按钮或命令面板打开。
  - **骨骼：**在骨骼上挂图片部件。在预览中拖动关节或部件可移动，按住 Shift 拖动可旋转。一个部件可以有多张图片（睁眼／闭眼、口型），并在它们之间切换。
  - **快速开始：**从角色立绘开始、新建空骨骼，或用尺寸相同的分层导出图片创建部件。
  - **动作：**骨骼动作是骨骼和部件的关键帧（移动、旋转、缩放、图片、不透明度，可设缓动）；序列帧动作逐帧播放图片。可指定一个**待机**动作，不循环的动作结束后会回到待机。
  - **表情：**更换部件的图片和不透明度，并微调骨骼姿势。没有骨骼的角色可用表情显示某张立绘。
- **Spine 导入：**同时选择 Spine 3.8 或 4.x 导出的 `.json`、`.atlas` 和贴图图片。可导入骨骼、图片切换、移动、旋转、缩放和淡入淡出。网格会显示为平面图片，约束会被忽略；工作室会列出未导入的内容。
- **角色元素播放动作：**
  - **属性栏：**新增**动作**、**表情**、**动作速度**和**显示方式**属性。
  - **时间轴：**为**动作**打关键帧，即可在指定时间播放动作；每个关键帧都会让动作从头开始。
  - **交互：**新增积木**播放动作**（可选择等待播放结束）和**设置表情**。
- **预设库（保存在用户文件夹，所有项目共用）：**
  - **场景：**在**预设**标签中（不选中任何元素，或选中某个元素时），用**保存为场景…**保存勾选的元素，连同它们的动画关键帧和由它们触发的交互。
    - **添加场景**会把它作为一个组放在背景之上。
    - **切换场景**会替换之前添加的场景，一键更换布景。
  - **角色：**保存角色及其立绘、骨骼、动作和表情，之后可添加到任何项目，或直接用于选中的角色元素。
  - **文件随之复制：**用到的图片和声音会复制到预设库；使用预设时再复制到项目中。

### 体验改进

- **简体中文：**立绘差分统一称为“立绘”，新的骨骼表情称为“表情”。
- **叠加窗口：**在另一个窗口上弹出的确认框会单独响应 Esc 和 Tab。

### 兼容性

- **项目文件格式 6。**旧项目无需转换即可打开；使用骨骼、动作或场景预设的项目需要 1.2.0。
- **模组 API 1.6：**
  - 新增 `motion` 和 `expression` 属性类型。
  - `PropDef.clock`：时间轴还会给出 `<key>Since`。
  - 新增 `Character.rig`、`motions`、`expressions`、`defaultMotion` 和 `Layer.presetGroup`。
  - 适用于 API 1.0–1.5 的模组可继续使用。

### 安装

**macOS：**解压后，将 `Visual Novel Editor.app` 移入“应用程序”。该应用尚未经过 Apple 公证；确认下载来源可信后，可按现有的首次启动流程运行：

```bash
xattr -cr "/Applications/Visual Novel Editor.app"
codesign --force --deep --sign - "/Applications/Visual Novel Editor.app"
```

**Windows：**解压后运行 `Visual Novel Editor.exe`。如果出现 SmartScreen 提示，确认来源可信后，可按现有流程选择“更多信息 → 仍要运行”。

**Linux：**解压后运行 `visual-novel-editor`。

**网页版：**解压后按其中的 README 用 Node.js 启动，然后在浏览器中打开编辑器。
